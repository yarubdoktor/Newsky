# حلبة العروش | Arena of Prestige

مشروع لعبة قتال حلبات للموبايل، قيد التأسيس.

## الحالة الحالية
- Prototype 0.1: نموذج متصفح محلي قابل للعب.
- حلبة دائرية مرسومة برمجيًا مع ممرات وغطاء مركزي.
- أربع شخصيات أولية: الحارس، الظل، العين، السيف.
- تحكم لمس عبر عصا افتراضية وأزرار هجوم ومهارة، مع دعم لوحة المفاتيح للاختبار.
- مباراة تجريبية مدتها 3 دقائق، ستة مقاتلين تجريبيين، إعادة ولادة، إقصاءات، واحتساب هيبة مؤقت.
- لا يوجد اتصال شبكي أو حسابات أو دردشة أو حفظ دائم في هذه المرحلة.

## التشغيل
افتح `index.html` في متصفح حديث. لا توجد مكتبات أو خطوات تثبيت مطلوبة.

## خارطة الطريق
1. اختبار الحركة والقتال وإصلاح الأخطاء.
2. فصل الأنظمة إلى وحدات واضحة وإضافة حفظ محلي للاعب.
3. تحسين الرسوم والمؤثرات والصوت وأداء الهاتف.
4. إضافة خادم موثوق للمباريات والحسابات والهيبة.
5. إضافة الكلانات والدردشة والتحالفات بعد استقرار القتال.

## قاعدة التطوير
كل مرحلة تُختبر قبل الانتقال للمرحلة التالية. لا يُدّعى نجاح اختبار أو بناء APK ما لم يتم تنفيذه والتحقق منه فعليًا.
